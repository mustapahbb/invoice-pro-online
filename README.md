# Invoice Pro Online

Aplikasi Invoice lengkap dengan Dashboard, Cetak A4, Kelola Klien, Logo, Backup/Restore.

**Offline-first** — data tersimpan di browser (localStorage).

## Cara Menjalankan Online (GitHub Pages)

1. Buka repository ini → **Settings** → **Pages**
2. Di bagian **Source**, pilih **Deploy from a branch**
3. Branch: `main` → Folder: `/ (root)` → Save
4. Tunggu 1–2 menit, lalu buka:
   **https://mustapahbb.github.io/invoice-pro-online/**

## Fitur

- Dashboard statistik (Total, Lunas, Belum Bayar, Jatuh Tempo)
- Buat / Edit / Hapus / Duplikat Invoice
- Template cetak profesional (A4)
- Upload logo perusahaan
- Kelola data klien + auto-fill
- Tandai lunas dengan 1 klik
- Cari & filter status
- Backup & Restore data (JSON)
- Pengaturan: prefix nomor, pajak default, rekening bank, NPWP

## Catatan

Data disimpan **lokal di browser** masing-masing perangkat.  
Gunakan fitur **Export Data** di menu Pengaturan untuk backup lintas perangkat.
